# Open Source Discord Community Specification for Atlantic Wars

Atlantic Wars is an open source Discord community specification for a medieval browser strategy game, providing a structured server layout, roles, permissions, onboarding messages, support templates, moderation workflows, and event guidance for a Portuguese-focused gaming community.

## Install

1. Clone or download this repository.
2. Open `discord-community-spec.md`.
3. Create a Discord server for the Atlantic Wars community.
4. Replace the official game URL, Discord invite URL, and support contact placeholders with the appropriate project information.
5. Create the categories, channels, roles, and permission rules described in the specification.
6. Configure onboarding, verification, moderation logging, and private support tickets.
7. Test the server with a non-staff account before launch.

## Use

1. Publish the welcome message in `#welcome`.
2. Publish and pin the rules in `#rules`.
3. Configure the Portuguese, English, and Spanish language roles.
4. Configure notification roles for game news, maintenance, events, and patch notes.
5. Use the announcement and maintenance templates for official updates.
6. Direct players to `#game-help`, `#strategy`, `#alliances`, and `#war-reports` for gameplay discussions.
7. Use the bug report and support ticket templates to collect issue details without exposing private information.
8. Record moderation actions and ticket activity in the restricted staff channels.
9. Organize recurring strategy discussions, village showcases, recruitment days, tournaments, and beginner coaching sessions.
10. Complete the launch checklist in `discord-community-spec.md`.
